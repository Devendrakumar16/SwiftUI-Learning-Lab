# SwiftUI Learning Lab - Modern UI & Animation Sandbox

A progressive multi-day exploratory SwiftUI laboratory featuring advanced layouts, interactive gestures, custom canvas drawings, glassmorphic UI cards, and state animations.

---

## 🛠️ Tech Stack & Architecture
`SwiftUI` `iOS 17+` `Custom ViewModifiers` `Animations & Transitions` `Swift`

- **Platform:** iOS 16.0+
- **Language:** Swift 5.10+
- **Framework:** SwiftUI
- **Architecture:** MVVM / Clean Architecture

---

## ✨ Key Features
- Daily progressive components exploring modern iOS interaction paradigms
- Custom animated background gradients and glassmorphism styling
- Complex gesture coordination and interactive drag-and-snap cards
- Reusable design tokens, typography scales, and modular card views

---

## 🚀 Getting Started

### Prerequisites
- macOS Sonoma or newer
- Xcode 15.0 or newer
- iOS Simulator or physical device running iOS 16+

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Devendrakumar16/SwiftUI-Learning-Lab.git
   cd SwiftUI-Learning-Lab
   ```
2. Open the project in Xcode:
   ```bash
   open *.xcodeproj 2>/dev/null || open *.xcworkspace
   ```
3. If CocoaPods is used:
   ```bash
   pod install
   open *.xcworkspace
   ```
4. Select your target simulator (e.g., iPhone 15 Pro) and press `Cmd + R` to build and run!
